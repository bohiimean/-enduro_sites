# Enduro — сайт

Django + PostgreSQL + Nuxt 3 + nginx. Решения и обоснования — в [CLAUDE.md](CLAUDE.md),
это источник истины по проекту.

## Запуск

```bash
make up          # поднять весь стек (создаст .env из .env.example)
make seed        # справочники курса, статусы поставки, демо-байк
make superuser   # администратор
make rates       # сервис курсов (отдельный профиль, тянет Chromium)
```

Сайт — http://localhost:8080, админка — http://localhost:8080/admin/

## Команды

`make help` покажет список. Ходовое: `make logs`, `make migrate`,
`make makemigrations`, `make shell`, `make psql`, `make down`.

## Сервис курсов

`rate-service/` — отдельный сервис, боевое место которого зарубежный VPS
(там `rate-service/docker-compose.yml`). Локально поднимается профилем:
`make rates`. Отдаёт **сырые** котировки; наценки и делитель юаня живут
в БД Django и правятся в админке, раздел «Курс и наценки».

## Состояние

Этапы 1–3 из 8: каркас, сервис курсов, курс на сайте.
Дальше — личный кабинет (этап 4), оплата внутри него (этап 5),
