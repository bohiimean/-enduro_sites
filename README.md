# Enduro — сайт

Django + PostgreSQL + Nuxt 3 + nginx. Решения и обоснования — в [CLAUDE.md](CLAUDE.md),
это источник истины по проекту.

## Запуск

```bash
make up          # поднять весь стек (создаст .env из .env.example)
make seed        # справочники курса, статусы поставки, демо-байк
make superuser   # администратор
make rates       # сервис курсов (отдельный профиль, тянет Chromium)
```

Сайт — http://localhost:8080, админка — http://localhost:8080/admin/

## Команды

`make help` покажет список. Ходовое: `make logs`, `make migrate`,
`make makemigrations`, `make shell`, `make psql`, `make down`.

## Сервис курсов

`rate-service/` — отдельный сервис, боевое место которого зарубежный VPS
(там `rate-service/docker-compose.yml`). Локально поднимается профилем:
`make rates`. Отдаёт **сырые** котировки; наценки и делитель юаня живут
в БД Django и правятся в админке, раздел «Курс и наценки».

## Состояние

Сделаны этапы 1–5 (каркас, сервис курсов, курс на сайте, личный кабинет,
оплата в кабинете — с живым alfabit ещё не проверена) и каталог, этап 7:
карточки ведутся в админке, у байка две цены от курса юаня.
Дальше — заказы и подтверждение номера (этап 6).

## Другие товары

В админке: «Каталог» → «Другие товары» → «Добавить». Укажите название,
описание, наличие и при необходимости срок поставки. Цена вводится вручную
в рублях и не зависит от курса; пустая цена отображается как «Цена по запросу».
Фотографии и характеристики добавляются строками ниже; у характеристики —
название, значение вместе с единицей измерения и порядок. Первые три
характеристики попадают в краткую карточку, первое фото становится главным.
Для показа на сайте включите «Опубликован»; новый товар по умолчанию — черновик.

Категории необязательны и создаются менеджером, собственного набора полей у
них нет. На главной выберите «Другие товары» (`/?section=goods`); доступны
фильтры по категории и наличию. Страница товара — `/goods/<slug>`, покупка
через менеджера. Байки продолжают использовать подробную форму и цены от юаня.

API: `GET /api/v1/catalog/goods/` (параметры `availability=stock|order`,
`category=<id>`, `limit`, `offset`), `GET /api/v1/catalog/goods/<slug>/`,
`GET /api/v1/catalog/goods-categories/`. Черновики публично недоступны.
После обновления примените миграции: `make migrate`.

## Панель управления

Админка использует Django Unfold: светлая тема SKL MOTO, меню по задачам,
вкладки в карточках байков и других товаров, миниатюры фото и фильтры.
Фото и характеристики можно перетаскивать за маркер слева; новые строки
сначала нужно сохранить, затем поменять порядок и сохранить ещё раз.
У байка пустые поля другого типа двигателя скрыты, заполненные остаются
видимыми, чтобы их можно было очистить. Проверка совместимости полей при
сохранении остаётся обязательной.

После обновления зависимостей пересоберите backend и worker:
`docker compose up -d --build backend worker`. Старт backend применяет
миграции и собирает статику Unfold; в рабочем окружении выполните эти шаги
штатным процессом деплоя. Шрифты и скрипты темы отдаются локально.
